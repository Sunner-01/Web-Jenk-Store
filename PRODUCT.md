# Voltio Store

## Platform
web

## Stack
Next.js, TypeScript, React, Jest, React Testing Library, Jenkins y Docker Desktop. Repositorio aportado por el usuario: Sunner-01/Web-Jenk-Store.

## Users and purpose
Cuatro estudiantes que deben demostrar un pipeline CI/CD mediante ocho contribuciones, dos por integrante. La tienda ofrece un caso visual con reglas de negocio comprobables. No representa un comercio real.

## Constraints
Proyecto base en D:\Jenkins-Pract, material de agregaciones separado del código inicial. Las ocho funciones se incorporan mediante módulos y pruebas independientes. Desarrollo local, despliegue Jenkins a Nginx local. Catálogo ficticio, carrito en memoria, sin pagos reales ni backend. Nombre Voltio Store delegado al implementador por el usuario.
